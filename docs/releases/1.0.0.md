A calm, local-first writing app for macOS. Markdown notes that stay markdown, a
daily note that writes itself, and a way to put a post on your blog without
leaving the window.

## Installing

Download `Tova_1.0.0_universal.dmg`, open it, and drag Tova to Applications.

Signed and notarized by Apple, so it opens without a warning and without any
right-click-to-open business. Universal — one download for Apple silicon and
Intel.

## Where your writing lives

In `~/Documents/Tova`, as `.md` files in ordinary folders. Open them in anything
else, keep them in a git repository, back them up however you already back
things up. Tova reads that folder; it does not own it.

Nothing is sent anywhere. There is no account, no sync service, and nothing to
sign in to.

## What it does on its own

Two things, both of which you are asked about the first time you open it, and
both of which live in Settings afterwards.

**Looks for a newer version** when it opens, once, and installs it quietly for
next time. Turn it off and Tova opens no connection at all.

**Grammar checking** is off, and its 15.6MB dictionary is not in this download —
it is fetched once if you say yes. It catches roughly half of common mistakes:
confusable words, repeated words, capitalisation. It reads words rather than
sentences, so subject-verb errors get through.

Spelling is checked either way. That is macOS's own checker, the one that knows
the words you have added.

## Publishing

A note can hold several posts, each with its own title, date and tags. Publishing
pushes to a GitHub repository and watches the deploy; the post is markdown on
the way in and markdown on the way out.

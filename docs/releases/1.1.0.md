Tables that lay themselves out, checkboxes you can tick, titles that wrap rather
than run off the edge — and a fix for the Mac quietly rewriting dashes in your
notes.

## Installing

Download `Tova_1.1.0_universal.dmg`, open it, and drag Tova to Applications.

If you already have Tova, it will find this itself the next time you open it —
unless you turned that off, in which case this is the download.

## The editor

**Tables render.** Type one however it comes out and the cells pad themselves
into columns the moment you click away. A rule is drawn under the header, the
pipes step back, and the whole thing stays ordinary markdown text — so you can
still type in any cell, and the file is still a file anything else can read.

**Checkboxes are boxes.** `- [ ]` draws one, and clicking it ticks the item.
The brackets come back when the caret is on that line, like every other marker.

**A long title wraps** onto a second line instead of scrolling sideways out of
sight, and wraps at the same width as the writing underneath it — including
when you narrow the line width in Appearance.

## A bug worth naming

**The Mac was rewriting your notes.** macOS substitutes a single long dash for
`---` as soon as a space follows it. In a markdown editor that is not a
nicety: `---` is a horizontal rule and it is a table's delimiter row, so a rule
drawn while you typed vanished on the next keystroke and a table stopped being
a table. Curly quotes did the same to anything inside a code block.

Tova now turns both off for itself. Nothing outside Tova changes — every other
app on your Mac keeps whatever substitutions you have set.

## Getting around

**The sidebar takes the keyboard.** `Cmd+S` moves focus to the rail, and the
arrow keys walk it.

**A section holding one note opens that note**, rather than a listing with a
single row in it.

**Settings reopens on the tab you left it on**, within a session.

## Smaller things

- Your avatar's default colour is drawn from the light background, rather than
  a blue that belonged to nothing
- The home page says which version of Tova this is
- About moved into Settings → General, where the rest of the app's own
  information lives
- A **tip jar**, in that same place and nowhere else
- A blank daily note is swept when the day turns, not only at launch — so an
  app left open overnight no longer collects one for every day it stayed open
- Thirteen advisories cleared out of the dependencies, and the editor's own
  CodeMirror brought up to date

## Where your writing lives

Unchanged: `~/Documents/Tova`, as `.md` files in ordinary folders. Nothing is
sent anywhere, there is no account, and there is nothing to sign in to.
